# EarnForge — Project Preview

EarnForge is a rewards-platform project focused on helping users discover activities and follow their progress through a structured interface.

## Project direction

- Activity and opportunity discovery
- A user dashboard and progress tracking
- Reward-related information and account views
- Careful handling of transaction-related events and records
- Clear boundaries between interface features and sensitive backend operations

## Development principles

The project emphasizes transparent behavior, documented system boundaries, careful accounting, and appropriate safeguards around reward-related operations.

## Status

**Under development.** Individual features and integrations may have different readiness levels. This page does not confirm that earning, redemption, real-money transactions, or payouts are currently available. Such functionality must not be assumed live unless it has been explicitly enabled and verified.
